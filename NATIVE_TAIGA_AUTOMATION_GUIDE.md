# 🎯 NATIVE TAIGA AUTOMATION - SIMPLEST POSSIBLE WORKFLOW

## ✅ WHAT EXACTLY TRIGGERS THE FLOW

**WEBHOOK TRIGGER** - The flow is triggered by **REAL-TIME WEBHOOKS** from Taiga:

1. **When a User Story is CREATED** with "action" in the title
2. **When a User Story is UPDATED** and now contains "action" in the title

**NO POLLING** - This is a true real-time integration using Taiga's native webhook system.

## 🔧 WORKFLOW COMPONENTS (4 NODES ONLY)

### 1. **Taiga Trigger** (Webhook)
- **Node Type**: `n8n-nodes-base.taigaTrigger`
- **Purpose**: Receives real-time webhook notifications from Taiga
- **Triggers On**: User Story CREATE and UPDATE events
- **Authentication**: Uses TaigaApi credentials

### 2. **Filter for 'action'** (IF Node)
- **Node Type**: `n8n-nodes-base.if`
- **Purpose**: Checks if story subject contains "action"
- **Logic**: `{{ $json.data.subject }} contains "action"`

### 3. **Create Task** (Taiga Node)
- **Node Type**: `n8n-nodes-base.taiga`
- **Resource**: Task
- **Operation**: Create
- **Purpose**: Creates a task linked to the user story

### 4. **Update Story** (Taiga Node)
- **Node Type**: `n8n-nodes-base.taiga`
- **Resource**: User Story
- **Operation**: Update
- **Purpose**: Adds automation note to the story description

## 🚀 SETUP INSTRUCTIONS

### Step 1: Configure Taiga API Credentials
1. Go to n8n → Credentials → Create New
2. Choose "Taiga API"
3. Enter:
   - **URL**: `http://taiga-docker-taiga-back-1:8000`
   - **Username**: `admin`
   - **Password**: `admin123`
4. Save as "Taiga API"

### Step 2: Import Workflow
1. Copy `/tmp/native-workflow.json` from n8n container
2. Import into n8n interface
3. Set Project ID to your Taiga project (likely `1`)

### Step 3: Activate Workflow
1. The workflow will automatically create a webhook in Taiga
2. No manual webhook configuration needed
3. Webhook URL is auto-generated by n8n

## 🔄 HOW THE CIRCULAR AUTOMATION WORKS

```
Taiga User Story Created/Updated (contains "action")
           ↓
    Taiga Webhook Trigger
           ↓
    Filter: Check for "action"
           ↓
    ┌─────────────────┐
    ↓                 ↓
Create Task      Update Story
    ↓                 ↓
Task appears    Story gets note
in Taiga        in Taiga
```

## ✨ WHAT HAPPENS EXACTLY

1. **User creates/edits a story** with "action" in title (e.g., "Need action plan for deployment")
2. **Taiga sends webhook** to n8n instantly
3. **n8n receives webhook** with full story data
4. **Filter checks** if story contains "action"
5. **IF YES**: 
   - Creates a new task under that story
   - Updates the story description with automation note
6. **User sees results** immediately in Taiga interface
