Step 2: Install Browser Userscripts

To add database management directly to your n8n and Kanboard interfaces:

  1. Install a userscript manager extension (like Tampermonkey or Greasemonkey)
  2. Open the userscript files below and install them:
    • n8n Integration: n8n-database-integration.user.js
    • Kanboard Integration: kanboard-database-integration.user.js
  3. Navigate to your n8n (localhost:5678) or Kanboard (localhost:8000) interface
  4. Look for the new database management buttons in the interface
